# Verification Rules

本文件定义 AI 完成任务前的默认验证规则。具体项目应在 `.ai/project.yml` 中填写可执行命令。

## Default Order

1. 静态检查：lint、typecheck、格式检查。
2. 单元测试：覆盖被修改模块的核心逻辑。
3. 集成或 E2E：覆盖跨模块、接口、数据、权限或部署路径。
4. 手工验证：当自动化测试不足时，记录步骤和观察结果。
5. 文档同步：公共接口、配置、部署流程、长期约定变更后更新对应文档。

## Evidence

完成任务时应说明：

- 执行了哪些命令。
- 关键结果是什么。
- 哪些验证无法执行，以及剩余风险。

## High-risk Changes

以下变更至少需要一项更强验证：

- API / 事件 / 数据 Schema 变更。
- 数据迁移、权限、安全、计费、审计。
- 并发、幂等、重试、补偿、分布式一致性。
- 部署、回滚、基础设施和运行时配置。
