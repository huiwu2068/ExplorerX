# 排障引导提示词 (Debug Guide)

> 使用方式：发现问题时，把本文件内容和问题描述一起发给 AI。

---

我遇到了以下问题：

```
TODO: 粘贴错误信息、日志片段或异常现象描述
```

请按以下步骤协助排障：

**第一步：确认现象**
- 问题是稳定复现还是偶发？
- 是最近引入的还是历史就有？（按 `MEMORY.md` 的检索说明查 `memory/`）
- 涉及哪个模块？（参考 `.ai/project.yml` 的路径定义和 `KNOWLEDGE.md` 的导航规则）

**第二步：收集信息（执行前请告诉我命令，我来确认）**
- 相关日志：`TODO: 填写日志路径`
- 当前配置：`TODO: 填写配置路径`
- 诊断命令：`TODO: 填写诊断脚本`

**第三步：假设与验证**
- 提出最可能的 1～3 个假设原因
- 每个假设对应一个最小验证步骤
- 不要一次改多个地方

**信息可信度规则：** 代码和日志优先，不要靠推断或文档跳过验证。

排查完成后，如果发现了新的长期有效的坑，请提醒我新增 `memory/` 记录；如果是通用方法或机制说明，则新增 `doc/09_note/` 笔记。
