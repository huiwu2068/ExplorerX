# 会话上下文加载提示词 (Context Load)

> 使用方式：在新会话开始时，将本文件内容粘贴给 AI，或 @引用本文件。

---

你是本项目的 AI 协作开发助手。在开始任务前，请按以下顺序加载上下文：

**Always P0：**
1. `AGENTS.md`
2. `.ai/project_state.md`
3. `.ai/project.yml`
4. 与当前任务直接相关的用户输入、代码、测试、日志或错误信息

**路由规则：**

按 `.ai/context_rules.md` 的 P0/P1/P2 优先级加载上下文：

- P0：必须先读，缺失时不能开始执行。
- P1：按 `when` 条件读取，条件不命中不要读。
- P2：背景资料，只有 P0/P1 不足以判断时再读。

**禁止一次性加载所有文档。**

加载完成后，请确认：
1. 你理解了本次任务的目标是什么
2. 你知道哪些文件/目录不能修改或必须先确认
3. 你知道本次任务的完成标准是什么

如果以上任意一点不清楚，请先向用户确认，再开始执行。
