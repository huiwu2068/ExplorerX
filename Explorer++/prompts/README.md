# prompts/

本目录存放项目级复用提示词，供 AI 工具直接引用或作为会话开场白使用。

## 文件说明

| 文件 | 用途 |
|------|------|
| `context_load.md` | 告诉 AI 本次会话应该优先加载哪些文档 |
| `code_review.md` | 代码审查时的标准检查项提示词 |
| `debug_guide.md` | 排障会话的引导提示词 |
| `task_kickoff.md` | 任务启动前的信息收集提示词 |

## 使用方式

直接将文件内容粘贴到 AI 会话开头，或在支持文件引用的工具中 `@prompts/xxx.md`。

这些提示词是给会话使用的“开场协议”，长期项目规则应写入 `AGENTS.md` 或 `.ai/`，不要散落在 prompts 中。
