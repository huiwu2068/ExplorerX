# 任务启动提示词 (Task Kickoff)

> 使用方式：开始一个新任务时，把本文件内容和任务描述一起发给 AI。

---

我要开始以下任务：

```
TODO: 粘贴任务描述或 TASK 文档链接
```

在开始执行前，请先帮我确认以下信息：

**任务理解**
- 这个任务完成后，系统会达到什么状态？（用一句话描述）
- 这个任务的核心约束是什么？（不能破坏什么）
- 有哪些场景明确不在本次任务范围内？

**风险评估**
- 这个任务的复杂度大概是 S/M/L/XL？
- 最可能遇到的风险点是什么？
- 如果实现中途发现方向不对，回滚方案是什么？

**信息缺口**
- 有没有需要先读的设计文档、ADR 或接口契约？
- 有没有不确定的地方需要在开始前向我确认？

确认以上信息后，请给出行动路线（分步骤），每步预期产出是什么。
不要直接开始写代码，先对齐理解。
