# 代码审查提示词 (Code Review)

> 使用方式：把本文件内容和待审查代码一起发给 AI。

---

请对以下代码进行审查，重点检查：

**正确性**
- [ ] 核心逻辑是否与设计文档/接口契约一致？
- [ ] 异常路径是否都被处理（空值、超时、并发冲突）？
- [ ] 是否存在隐含的竞态条件或数据不一致风险？

**安全性**
- [ ] 是否有未校验的外部输入（SQL 注入、路径穿越、反序列化）？
- [ ] 权限检查是否在正确的层次执行，是否可被绕过？
- [ ] 密钥、Token、敏感数据是否可能被日志或错误信息泄露？

**可维护性**
- [ ] 是否引入了与项目现有风格不一致的模式？
- [ ] 是否有可以复用已有工具/库但却重复实现的逻辑？
- [ ] 公共接口变更是否同步更新了文档和测试？

**可观测性**
- [ ] 关键路径是否有足够的日志（但不过度）？
- [ ] 错误是否有足够的上下文供排障使用？

**项目约定**
- [ ] TODO: 补充本项目特有的检查项（如：是否遵守 API 版本约定）

如发现问题，请按严重程度分类：🔴 必须修复 / 🟡 建议修复 / 🟢 可选优化。
